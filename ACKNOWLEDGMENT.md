## Built with

| Tool | What it does for `cfdns` |
|---|---|
| [Cloudflare API](https://developers.cloudflare.com/api/) | DNS records, proxy settings, and zone management |
| [Caddy](https://caddyserver.com/) | Web server and reverse proxy, with automatic HTTPS |
| [Let's Encrypt](https://letsencrypt.org/) | Free, trusted certificates (issued through Caddy) |
| [jq](https://jqlang.github.io/jq/) | Reading and building JSON in the shell |
| [curl](https://curl.se/) | Talking to the Cloudflare API |
| [GNU Bash](https://www.gnu.org/software/bash/) | The language `cfdns` is written in |
| [GitHub](https://github.com/) and [GitHub CLI](https://cli.github.com/) | Hosting the code and the one-line installer |
| [Debian](https://www.debian.org/) | The operating system it was developed and tested on |
